🎓 Student Analytics Dashboard Pro

A modern, interactive Student Performance Analytics Dashboard built with Streamlit and Python. This application enables educators, students, and analysts to explore academic performance data through dynamic visualizations, filters, and performance insights.

---

🚀 Features

📊 Advanced Analytics

- Student performance overview
- Average marks analysis
- Attendance tracking
- Performance statistics
- Real-time KPI cards

📈 Interactive Visualizations

- Bar Charts
- Pie Charts
- Subject-wise Analysis
- Gender-based Performance Comparison
- Performance Distribution Charts

🔍 Dynamic Filtering

- Filter by Subject
- Filter by Gender
- Interactive dashboard controls
- Real-time data updates

📋 Student Details

- Detailed student records
- Searchable and organized data view
- Performance insights for individual students

📁 Dataset Management

- CSV file upload support
- Automatic dataset loading
- Missing value handling
- Data preprocessing

🎨 Modern UI/UX

- Dark theme design
- Responsive layout
- Custom CSS styling
- Interactive sidebar navigation
- Professional dashboard appearance

---

🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- NumPy

⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/Student-Analytics-Dashboard-Pro.git

Navigate to the project directory:

cd Student-Analytics-Dashboard-Pro

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
